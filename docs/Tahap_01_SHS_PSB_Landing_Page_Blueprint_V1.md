# Tahap 01 — SHS PSB Landing Page Blueprint V1

**Project:** Suria Harapan School — Penerimaan Siswa Baru  
**Document Version:** V1  
**Document Type:** Product / Content / Conversion Blueprint  
**Primary Output:** Bilingual PSB Landing Page + Admission Lite  
**Language:** Bahasa Indonesia & English  
**Delivery Target:** 3 Days  
**Status:** Draft for Scope & Content Freeze  

---

# 1. Purpose

Dokumen ini menjadi acuan utama dalam pengembangan landing page Penerimaan Siswa Baru Suria Harapan School.

Blueprint ini bertujuan untuk:

1. Mengunci tujuan utama landing page.
2. Menentukan target pengguna.
3. Menentukan positioning dan karakter komunikasi.
4. Menentukan struktur informasi.
5. Menentukan conversion flow.
6. Menentukan CTA utama dan sekunder.
7. Menentukan kebutuhan konten.
8. Menentukan kebutuhan foto dan video.
9. Menentukan flow PSB.
10. Menentukan kebutuhan bilingual.
11. Menentukan kebutuhan lead capture.
12. Membatasi scope agar dapat diselesaikan dalam waktu 3 hari.
13. Menjadi fondasi untuk pengembangan Portal PSB pada fase berikutnya.

---

# 2. Project Goal

Landing page PSB SHS bukan sekadar halaman informasi sekolah.

Landing page harus mampu membawa calon orang tua dari:

> **Belum mengenal SHS → tertarik → memahami SHS → percaya → melakukan tindakan.**


- inquiry;
- school visit;
- consultation;
- admission lead;
- pendaftaran awal.

# 43. Motion Principle

Animation harus mendukung storytelling.

Recommended:

- subtle image reveal;
- fade / slide;
- typography reveal;
- number animation;
- horizontal gallery;
- gentle hover.

Hindari:

- excessive parallax;
- bouncing elements;
- animation pada semua komponen;
- scroll hijacking.
