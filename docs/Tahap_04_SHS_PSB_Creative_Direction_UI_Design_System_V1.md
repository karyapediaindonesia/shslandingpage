# 3. Creative Direction — Primary

Direction utama:

> **Bright Editorial School Life**

Definisi:

> Pengalaman digital yang menggabungkan visual sekolah nyata, fotografi kehidupan siswa, tipografi berani, komposisi editorial, warna cerah yang terkontrol, dan UI yang ringan.

Formula:

```text
REAL PHOTOGRAPHY
×
BOLD TYPOGRAPHY
×
EDITORIAL GRID
×
BRIGHT ACCENTS
×
REAL SCHOOL MOMENTS
×
CLEAN UI
×
SUBTLE PLAYFULNESS
```

---

# 4. Creative Personality

Karakter visual utama:

- bright;
- active;
- warm;
- modern;
- youthful;
- confident;
- human;
- authentic;
- optimistic;
- energetic;
- clear.

Karakter yang harus dihindari:

- luxury school;
- formal corporate school;
- preschool-only visual;
- startup SaaS;
- futuristic tech;
- overly minimal monochrome;
- excessive pastel;
- excessive cartoon.

---

# 5. Visual Positioning

SHS harus berada di antara:

```text
TRUSTED SCHOOL
        ×
YOUTH CULTURE
        ×
CONTEMPORARY EDUCATION
```

Bukan hanya:

```text
SCHOOL BROCHURE ON WEB
```

dan bukan:

```text
CREATIVE AGENCY EXPERIMENT
```

---

# 6. Emotional Target

Saat orang tua membuka website:

> “Sekolah ini terlihat aktif, modern, serius mendidik, tetapi tetap hangat.”

Saat siswa melihat:

> “Sekolah ini kelihatannya hidup dan seru.”

Saat tim SHS melihat:

> “Ini terasa seperti SHS, bukan template sekolah mana pun.”

---

# 7. Visual Hierarchy Principle

Setiap section mengikuti hierarki:

```text
1. IMAGE / HEADLINE
2. KEY MESSAGE
3. SUPPORTING COPY
4. PROOF
5. CTA
```

Jangan membuat semua elemen memiliki visual weight yang sama.

---

# 8. Layout Philosophy

Gunakan:

- asymmetrical grid;
- varied image sizes;
- large whitespace;
- editorial offset;
- occasional full-bleed media;
- alternating composition;
- controlled overlap.

Hindari:

- semua section center aligned;
- semua section 3-column cards;
- semua image ratio sama;
- setiap block dibungkus card;
- layout terlalu simetris.

---

# 9. Grid System

## Desktop

Recommended:

```text
12-column grid
Max content width: 1200–1320px
Outer margin: 48–80px
Gutter: 20–32px
```

Recommended content width:

```text
Main editorial content: 1120–1240px
Wide visual sections: up to 1440px
```

## Tablet

```text
8-column grid
Outer margin: 32–48px
Gutter: 20–24px
```

## Mobile

```text
4-column grid
Outer margin: 20–24px
Gutter: 12–16px
```

# 11. Container Rules

Use three container types:

## A. Standard Container

For:

- navigation;
- text-heavy sections;
- FAQ;
- form.

```text
Max width: 1200–1280px
```

## B. Editorial Wide Container

For:

- student life;
- beyond classroom;
- photography collage.

```text
Max width: 1360–1440px
```

## C. Full Bleed

For:

- hero media;
- selected photo moments;
- final visual CTA.

Use intentionally, not on every section.

# 12. Color Strategy

Bright does not mean many colors.

Use:

```text
1 Primary Brand Color
1 Strong Dark Neutral
1 Light Neutral
2–3 Accent Colors
```

---

# 13. Color Roles

## Primary Brand Color

Use for:

- primary CTA;
- selected highlights;
- active states;
- key section accents.

## Dark Neutral

Use for:

- body text;
- primary headings;
- footer;
- strong contrast sections.

## Light Neutral

Use for:

- page background;
- form surfaces;
- subtle section separation.

## Accent Colors

Use for:

- learning level identity;
- editorial labels;
- timeline moments;
- selected icons;
- small graphic highlights.

Do not use all accents in one component.

---

# 14. Color Distribution Rule

Recommended visual ratio:

```text
60% Neutral
25% Primary
15% Accent
```

This is a guidance, not a strict technical rule.

The page should still feel bright through:

- photography;
- whitespace;
- accent color;
- typography;
- motion.

Not through rainbow UI.

---

# 15. Contrast Rule

All text must maintain sufficient contrast.

Avoid:

- yellow text on white;
- pastel text on pastel;
- low-contrast gray for body;
- colored body text on photo without overlay.

CTA text must remain highly readable.

---

# 16. Typography Strategy

Use two-font logic if brand guidelines allow.

## Display Typeface

Purpose:

- hero headline;
- section headline;
- large statistics;
- campaign messages.

Character:

- expressive;
- modern;
- confident;
- editorial;
- slightly youthful.

## Utility Typeface

Purpose:

- body;
- navigation;
- form;
- FAQ;
- small labels.

Character:

- clean;
- readable;
- neutral;
- digital friendly.

---

Recommended starting scale:

```text
Display XL      72–96px
Display L       56–72px
H1              48–64px
H2              36–48px
H3              28–36px
H4              22–28px
Body L          18–20px
Body            16–18px
Small           14–15px

```

---

# 18. Typography Scale — Mobile

Recommended:

```text
Display XL      44–56px
H1              38–48px
H2              30–38px
H3              24–30px
Body L          17–18px
Body            15–17px
Small           13–14px
```

Avoid shrinking typography too aggressively.

---

# 19. Typography Style Rules

Use:

- strong hierarchy;
- short headline;
- controlled line length;
- occasional uppercase eyebrow;
- large editorial numbers;
- bold emphasis sparingly.

Avoid:

- uppercase long paragraphs;
- center alignment for long copy;
- excessive font weights;
- excessive letter spacing.

---

# 20. Line Length

Recommended:

```text
Body text:
50–75 characters per line

Hero supporting text:
35–55 characters per line
```

Long lines reduce readability.

---

# 21. Hero Design Direction

Hero must immediately communicate:

```text
SHS
+
ENERGY
+
REAL STUDENT LIFE
+
ADMISSION ACTION
```

Recommended composition:

Desktop:

```text
Left:
Eyebrow
Large headline
Supporting copy
CTA

Right:
Large real image / video
```

Alternative:

- asymmetrical split;
- oversized visual;
- partial overlap;
- image breaking grid.

Avoid:

- centered hero with small text over generic image;
- gradient blob background;
- floating glass cards;
- decorative 3D icons.

---

# 22. Hero Media Treatment

Priority:

```text
1. Real video
2. Real photography
3. Real photo collage
```

Use:

- natural lighting;
- authentic expression;
- motion;
- school environment;
- students interacting.

Optional:

- subtle dark overlay for readability;
- graphic line / small label.

Do not:

- over-filter;
- apply cinematic dark grading;
- blur backgrounds artificially;
- use AI-generated children.

---

# 23. Image Treatment

Photography should feel:

- real;
- bright;
- natural;
- candid;
- active;
- warm.

Image treatment:

- minimal color correction;
- consistent temperature;
- natural skin tone;
- moderate contrast;
- limited saturation boosting.

---

# 24. Image Cropping Strategy

Mix:

```text
16:9
4:3
3:2
4:5
1:1
```

Do not force all images to:

```text
1:1 rounded cards
```

Editorial variation is intentional.

---

# 25. Border Radius

Use sparingly.

Recommended:

```text
Small UI: 8–12px
Buttons: 8–12px
Forms: 8–12px
Media: 0–16px depending section
```

Avoid:

```text
24–32px on every block
```

Do not make everything “soft SaaS”.

---

# 26. Shadow Strategy

Use minimal shadows.

Recommended:

- none for most layout blocks;
- subtle shadow only for:
  - dropdown;
  - mobile menu;
  - modal;
  - floating sticky CTA;
  - selected elevated components.

Avoid decorative box shadows on every card.

---

# 27. Border Strategy

Prefer:

- 1px subtle neutral border;
- thin divider;
- editorial line;
- section separator.

Borders may help create structure without cards.

---

# 28. Button System

Use maximum three button types.

---

## 28.1 Primary Button

Purpose:

- Start Admission;
- Submit form.

Visual:

- solid primary color;
- high contrast;
- medium radius;
- clear label;
- optional arrow.

---

## 28.2 Secondary Button

Purpose:

- Book School Tour;
- Explore SHS.

Visual:

- outline or light surface;
- dark text;
- subtle hover.

---

## 28.3 Text Link

Purpose:

- Explore Level;
- Read More;
- See Student Life.

Visual:

```text
Label →
```

Avoid many button shapes.

---

# 29. Button Size

Desktop:

```text
Height: 48–56px
Padding X: 20–28px
```

Mobile:

```text
Height: 48–52px
Full-width when conversion-critical
```

Tap target minimum:

> 44px.

---

# 30. Button Copy Rules

Prefer action-led copy.

Use:

- Start Admission
- Book a School Tour
- Talk to Admission
- Explore Primary
- Get Tuition Information

Avoid:

- Learn More everywhere
- Click Here
- Submit only

---

# 31. Icon Strategy

Icons should be used only when they improve comprehension.

Recommended:

- simple line icons;
- consistent stroke;
- one icon family.

Avoid:

- icon on every card;
- decorative icons with no function;
- mixing multiple icon styles;
- emojis as UI icons.

---

# 32. Illustration Strategy

V1 does not require custom illustration.

If used:

- minimal;
- abstract;
- editorial;
- derived from brand shape;
- secondary to photography.

Do not use:

- generic education illustrations;
- cartoon students;
- random blobs;
- AI-looking mascots.

---

# 33. Graphic Accent Strategy

Use small graphic devices to give personality:

- underline;
- marker highlight;
- circle stroke;
- directional arrow;
- small dot;
- editorial label;
- section number.

Example:

```text
01 — WHY SHS
```

Use intentionally.

---

# 34. Handwritten Accent

Optional.

Use only for:

- one or two short phrases;
- visual emphasis;
- “Shine” moment.

Avoid handwriting for:

- navigation;
- paragraph;
- form;
- accessibility-critical copy.

---

# 35. Section Numbering

Can be used to reinforce editorial personality.

Example:

```text
01
WHY SHS
```

```text
02
LEARNING JOURNEY
```

Use consistently if adopted.

Do not mix numbered and unnumbered sections randomly.

---

# 47. FAQ Design

Keep simple.

Use:

- clean accordion;
- thin divider;
- strong question typography;
- minimal icon.

Avoid:

- large cards;
- excessive colored backgrounds;
- long answer blocks.

---

# 48. Form Design System

Form must feel light and easy.

Use:

- visible label;
- large input height;
- clear spacing;
- simple validation;
- minimal visual chrome.

Input:

```text
Height: 48–56px
Radius: 8–12px
Border: subtle
```

Textarea:

```text
Min height: 120px
```

---

# 49. Form Layout — Desktop

Recommended:

```text
Two-column form when logical
```

Example:

```text
Parent Name      WhatsApp
Email            Student Name
Level            Grade
Academic Year    Interest
```

Do not create 3-column dense form.

---

# 50. Form Layout — Mobile

Use:

```text
1 column
```

No side-by-side inputs unless extremely short.

---

# 51. Form Focus State

Focus must be clearly visible.

Use:

- primary border;
- subtle focus ring.

Do not rely only on color change too subtle to notice.

---

# 52. Form Error State

Use:

- clear red / error tone;
- inline message;
- descriptive text.

Example:

```text
Please enter a valid WhatsApp number.
```

Avoid:

```text
Error.
```

---

# 53. Form Success State

After submission:

- clear success icon / check;
- human message;
- next action;
- WhatsApp option.

Do not simply show:

> “Form submitted successfully.”

---

# 54. Navigation Design

Desktop:

- clean;
- transparent or light;
- strong logo;
- right-aligned CTA.

On scroll:

- solid background;
- slight border;
- no heavy shadow.

Mobile:

- simple drawer;
- large touch area;
- admission CTA visible.

---

# 55. Sticky Mobile CTA

Recommended:

```text
[WhatsApp] [Start Admission]
```

Visual:

- compact;
- safe area aware;
- high contrast.

Hide:

- while mobile keyboard is open;
- when form submit area is visible if obstructive.

---

# 56. Footer Design

Footer should feel deliberate, not leftover.

Use:

- dark neutral or primary dark;
- strong logo;
- concise contact info;
- navigation;
- social;
- language;
- legal.

Optional short brand line:

> Shine and Be a Blessing.

---

# 57. Motion Direction

Motion should communicate:

- energy;
- progression;
- life.

Use:

- image reveal;
- subtle fade;
- controlled slide;
- number count;
- hover crop;
- underline motion;
- timeline progression.

Avoid:

- bounce;
- floating objects;
- constant looping UI animation;
- scroll hijacking;
- excessive parallax.

---

# 58. Motion Duration

Recommended:

```text
Fast UI:
120–180ms

Standard:
200–300ms

Editorial reveal:
400–700ms
```

Use natural easing.

Respect:

```text
prefers-reduced-motion
```

---

# 59. Hover Strategy

Hover can enhance:

- level panel;
- image caption;
- CTA;
- text link.

Do not hide critical content only on hover.

---

# 60. Scroll Reveal Strategy

Maximum:

- one reveal per section group;
- stagger small elements.

Avoid:

```text
every text line animates independently
```

---

# 61. Responsive Principle

Do not “shrink desktop”.

Recompose.

Desktop:

```text
Editorial
Asymmetric
Wide
```

Mobile:

```text
Direct
Readable
Tactile
Fast
```

---

# 62. Mobile Visual Priorities

Order:

```text
1. Headline
2. Real photo
3. CTA
4. Key proof
5. Short copy
```

Reduce:

- decorative graphics;
- complex overlaps;
- non-essential motion;
- wide collage complexity.

---

# 63. Mobile Image Rules

Use:

- full-width image;
- portrait crops;
- 4:5 where appropriate;
- lazy loading;
- optimized formats.

Avoid overly short landscape photos that become visually weak on mobile.

---

# 64. Desktop Visual Priorities

Use desktop to express:

- asymmetry;
- large scale;
- negative space;
- oversized type;
- varied media placement.

But conversion must remain clear.

---

# 65. Desktop Hero Ratio

Recommended:

```text
Text: 40–45%
Media: 55–60%
```

Alternative:

```text
Media full-bleed + text overlay
```

Only if readability remains strong.

---

# 66. Icon / Logo Asset Rules

Use official:

- SHS logo;
- partner logo;
- accreditation logo.

Never:

- redraw official logo;
- distort proportions;
- apply random gradient;
- add shadow unless guideline permits;
- recolor without permission.

---

# 67. Logo Clear Space

Follow official guideline if available.

If not:

> maintain generous clear space at least equivalent to the logo symbol height / meaningful internal unit.

Do not crowd logo with navigation.

---

# 68. Photography Content Mix

Recommended media mix:

```text
30% Learning
20% Friendship / Community
15% Sport
10% Art / Music
10% Science / Technology
10% Teacher Interaction
5% Campus / Facilities
```

This is guidance only.

---

# 69. Photography Quality Rule

Minimum preferred:

```text
Hero:
≥ 1920px width

Standard web:
≥ 1200px width

Portrait:
≥ 900px width
```

Avoid upscaling low-resolution social screenshots.

---

# 70. Image Format

Recommended:

```text
AVIF
WebP
```

Fallback:

```text
JPEG / PNG
```

Use SVG for:

- logos;
- simple icons;
- vector graphic accents.

---

# 71. Video Treatment

Hero video:

```text
Muted
Loop
Autoplay only if allowed
Poster image
Short duration
Compressed
```

Avoid:

- long cinematic video;
- background audio autoplay;
- large file blocking first load.

---

# 72. Performance Budget — Visual

Recommended initial targets:

```text
Hero image < 300–400 KB if possible
Below-fold images lazy-loaded
Hero video kept highly compressed
No large animation libraries unless needed
```

Visual quality must be balanced with page speed.

---

# 73. Anti-AI Visual Rules

Do not use repeated patterns commonly associated with AI-generated web design.

Avoid:

```text
• Gradient purple-blue backgrounds
• Glassmorphism cards
• Floating glowing circles
• Blob illustrations
• 3 identical feature cards
• 6 icon cards
• Gradient headlines
• Rounded rectangle everywhere
• Generic “future education” visuals
• Fake statistics
• Fake testimonials
• AI-generated student portraits
• Decorative dashboards
• Random sparkles
• Repetitive centered sections
```

---

# 74. Anti-Template Rule

At least 4 major sections should have clearly different composition:

```text
Hero
Why SHS
Student Life
Admission
```

The page should not look like:

```text
Heading
3 cards
Heading
3 cards
Heading
3 cards
```

# 86. Dark Section Usage

Dark sections can add rhythm.

Recommended candidates:

- Learning at SHS;
- Final CTA;
- Footer.

Do not use dark background on too many sections.

---

# 87. Accent Section Usage

Accent background may be used for:

- Why SHS;
- Admission Timeline;
- Start Admission.

Use only one strong accent section at a time.

---

# 88. Brand Motto Placement

“Shine and Be a Blessing” can appear:

- hero secondary line;
- footer;
- a dedicated editorial moment.

Do not repeat it on every section.

---

# 89. Bilingual UI Rules

ID and EN must use the same design system.

Allow differences in:

- line break;
- copy length;
- headline size adjustment;
- button width.

Do not force identical line wrapping.

---

# 90. Language Width Consideration

English may be shorter or longer depending phrase.

UI components must:

- allow flexible width;
- avoid fixed button width;
- avoid clipping labels.

---

# 91. Translation-Friendly Components

Avoid:

- text embedded in images;
- text embedded in decorative SVG;
- fixed-height text cards.

All visible copy should remain editable HTML text where possible.

---

# 92. Accessibility Visual Rules

Minimum:

- 4.5:1 contrast for normal text where applicable;
- clear focus state;
- readable base font;
- large tap targets;
- meaningful alt text;
- not relying solely on color.

Before launch, ask:

- [ ] Does this look like a generic education template?
- [ ] Are there too many rounded cards?
- [ ] Are there too many icons?
- [ ] Is there unnecessary gradient?
- [ ] Are photos real SHS photos?

- [ ] Is the copy specific to SHS?

- [ ] Is there sufficient editorial asymmetry?
